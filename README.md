# AirWrite: Gesture-Based Text Recognition

## Project Description

AirWrite is a computer vision project that allows users
to write characters in the air using their finger.

The system tracks the user's hand through a webcam,
captures the fingertip movement, and converts the
air-written characters into digital text.

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- OCR

## Main Features

- Hand detection
- Fingertip tracking
- Air writing
- Gesture recognition
- Character recognition
- Digital text output
